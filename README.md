> Your 3am idea isn't genius, it's the third coffee. Write it down anyway — the fourth one is.

One line I would send back to my younger self if a single line were all I got: the 3am idea isn't genius, it's the third coffee — but write it down anyway, because the fourth one is.

## Run it

```sh
python3 main.py
```

Prints the line and writes it to `/output/entry.txt`.
